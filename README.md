## 🌟 Key Features

- **⚡ 5+ MB/s High-Speed Download Engine:** Built-in multi-connection downloader that bypasses Indian ISP throttling (Jio / Airtel / Vi) with pause, resume, and live speed gauges.
- **📺 100% Pure Offline Video Player:** Watch downloaded movies & web series episodes directly from device storage without internet buffering.
- **🔄 YouTube-Style Player Gestures:**
  - Swipe up from bottom in landscape mode for instant episodes drawer.
  - Double tap left/right for 10s instant seek.
  - Swipe vertically on left for Brightness & right for Volume.
  - Long press anywhere on screen for instant 2X fast-forward.
- **🕒 Smart Watch History & Timestamp Auto-Resume:** Automatically tracks your exact seconds and auto-resumes with a floating notification banner.
- **🔄 GitHub In-App Auto Update:** Automatically detects new releases from GitHub and updates in 1 click.
- **💎 1080P & 4K HDR 10-Bit Color Pipeline:** AMOLED-tuned visual playback engine with multi-source adaptive resolution switching.
